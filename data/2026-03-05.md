### [1] [GraphLake: A Purpose-Built Graph Compute Engine for Lakehouse](https://arxiv.org/abs/2603.03705)
*Shige Liu,Songting Chen,Chengjie Qin,Mingxi Wu,Jianguo Wang*

Main category: cs.DB

TL;DR: GraphLake 是一个专为 Lakehouse 构建的图计算引擎，基于 TigerGraph 实现，通过仅加载图拓扑结构、引入图感知缓存机制和针对 Lakehouse 优化的并行原语，在启动时间和查询效率上显著优于当前最先进的 PuppyGraph。


<details>
  <summary>Details</summary>
Motivation: 现有 Lakehouse 图计算引擎（如 PuppyGraph）在启动时间和查询效率方面存在不足，难以高效支持基于 Lakehouse 表的图分析任务。因此，需要一种专门针对 Lakehouse 架构优化的高性能图计算引擎。

Method: GraphLake 基于 TigerGraph 构建，将 Lakehouse 表映射为标签属性图中的顶点和边类型，并使用 GSQL 支持图分析。为加速启动，仅加载图拓扑；为提升查询效率，引入图感知缓存机制和两种 Lakehouse 优化的并行原语。

Result: 实验表明，GraphLake 在启动时间和查询时间上均显著优于当前最先进的 Lakehouse 图计算引擎 PuppyGraph。

Conclusion: GraphLake 通过架构和算法层面的多项优化，有效解决了 Lakehouse 上图分析的性能瓶颈，为 Lakehouse 提供了高效、低延迟的图计算能力。

Abstract: In this paper, we introduce GraphLake, a purpose-built graph compute engine for Lakehouse. GraphLake is built on top of the commercial graph database TigerGraph. It maps Lakehouse tables to vertex and edge types in a labeled property graph and supports graph analytics over Lakehouse tables using GSQL. To minimize startup time, it loads only the graph topology. Furthermore, it introduces a series of techniques to ensure query efficiency over Lakehouse tables, including a graph-aware caching mechanism and two Lakehouse-optimized parallel primitives. Extensive experiments demonstrate that GraphLake significantly outperforms PuppyGraph, the current state-of-the-art graph compute engine for Lakehouse, by achieving both lower startup and query time.

### [2] [Towards Effective Orchestration of AI x DB Workloads](https://arxiv.org/abs/2603.03772)
*Naili Xing,Haotian Gao,Zhanhao Zhao,Shaofeng Cai,Zhaojing Luo,Yuncheng Wu,Zhongle Xie,Meihui Zhang,Beng Chin Ooi*

Main category: cs.DB

TL;DR: 该论文探讨了将AI直接集成到数据库引擎中（AIxDB）所面临的挑战，并提出初步设计方案以优化AI驱动查询的性能。


<details>
  <summary>Details</summary>
Motivation: 当前将数据导出至机器学习运行时的做法存在高开销、对数据漂移鲁棒性差以及攻击面扩大等问题，尤其在多租户、异构数据系统中更为突出。因此，有必要研究将AI与数据库深度融合的架构。

Method: 论文分析了AIxDB系统中联合查询处理与模型执行的关键挑战，包括查询优化、执行调度、异构硬件上的分布式执行，并重新审视事务管理与访问控制机制以支持AI生命周期管理、缓解数据漂移并保障数据安全。

Result: 提出了一个面向AIxDB的设计方案，并展示了初步实验结果，表明该设计对提升AI驱动查询的端到端性能具有关键作用。

Conclusion: 将AI直接嵌入数据库引擎虽具潜力，但需系统性地解决查询处理、资源调度、安全控制等多方面挑战，方能实现高效、安全、鲁棒的AI原生数据管理系统。

Abstract: AI-driven analytics are increasingly crucial to data-centric decision-making. The practice of exporting data to machine learning runtimes incurs high overhead, limits robustness to data drift, and expands the attack surface, especially in multi-tenant, heterogeneous data systems. Integrating AI directly into database engines, while offering clear benefits, introduces challenges in managing joint query processing and model execution, optimizing end-to-end performance, coordinating execution under resource contention, and enforcing strong security and access-control guarantees.
  This paper discusses the challenges of joint DB-AI, or AIxDB, data management and query processing within AI-powered data systems. It presents various challenges that need to be addressed carefully, such as query optimization, execution scheduling, and distributed execution over heterogeneous hardware. Database components such as transaction management and access control need to be re-examined to support AI lifecycle management, mitigate data drift, and protect sensitive data from unauthorized AI operations. We present a design and preliminary results to demonstrate what may be key to the performance for serving AIxDB queries.

### [3] [Efficient Query Rewrite Rule Discovery via Standardized Enumeration and Learning-to-Rank](https://arxiv.org/abs/2603.04169)
*Yuan Zhang,Yuxing Chen,Yuekun Yu,Jinbin Huang,Rui Mao,Anqun Pan,Lixiong Zheng,Jianbin Qin*

Main category: cs.DB

TL;DR: SLER is a scalable system for automated query rewrite rule discovery that combines standardized template enumeration with learning-to-rank to overcome redundancy and scalability issues, enabling the construction of the largest empirically validated rule library (over 1 million rules) supporting complex query plans.


<details>
  <summary>Details</summary>
Motivation: Existing automated query rewrite rule enumeration methods face exponential search spaces, severe redundancy, and poor scalability, especially for complex query plans with five or more operators, limiting their practical utility in real-world database optimization.

Method: SLER introduces standardized templates—abstract representations of query plans preserving operator structure but removing data-specific details—to eliminate structural redundancies. It integrates a learning-to-rank model to pre-filter promising template pairs, guiding efficient enumeration and enabling scalable rule generation for large and complex templates.

Result: Evaluated on over 11,000 real-world SQL queries from open-source and commercial workloads, SLER automatically built a rewrite rule repository exceeding 1 million empirically validated rules—the largest to date—and supports query plan templates up to channel-level depth in complexity.

Conclusion: SLER’s template-driven design and learned ranking mechanism offer unprecedented scalability and extensibility, enabling discovery of intricate query transformations and paving the way for next-generation query optimizers powered by comprehensive, adaptive rule spaces.

Abstract: Query rewriting is essential for database performance optimization, but existing automated rule enumeration methods suffer from exponential search spaces, severe redundancy, and poor scalability, especially when handling complex query plans with five or more nodes, where a node represents an operator in the plan tree. We present SLER, a scalable system that enables efficient and effective rewrite rule discovery by combining standardized template enumeration with a learning to rank approach. SLER uses standardized templates, abstractions of query plans with operator structures preserved but data specific details removed, to eliminate structural redundancies and drastically reduce the search space. A learn to rank model guides enumeration by pre filtering the most promising template pairs, enabling scalable rule generation for large node templates. Evaluated on over 11000 real world SQL queries from both open source and commercial workloads, SLER has automatically constructed a rewrite rule repository exceeding 1 million rules - the largest empirically validated rewrite rule library to date. Notably, at the scale of one million rules, SLER supports query plan templates with complexity up to channel level depth. This unprecedented scale opens the door to discovering highly intricate transformations across diverse query patterns. Critically, SLER's template driven design and learned ranking mechanism are inherently extensible, allowing seamless integration of new and complex operators, paving the way for next generation optimizers powered by comprehensive, adaptive rule spaces.

</details>


### [4] [Scalable Join Inference for Large Context Graphs](https://arxiv.org/abs/2603.04176)
*Shivani Tripathi,Ravi Shetye,Shi Qiao,Alekh Jindal*

Main category: cs.DB

TL;DR: 提出一种结合统计剪枝与大语言模型（LLM）推理的可扩展连接关系推断方法，用于从结构化数据库构建高质量上下文图。


<details>
  <summary>Details</summary>
Motivation: 在构建上下文图时，无效的表连接会导致歧义和重复记录，影响图质量；现有纯统计方法缺乏语义理解，而纯LLM方法易产生幻觉，因此需要一种兼顾准确性、可扩展性与语义合理性的混合方法。

Method: 采用两阶段混合策略：首先通过统计方法识别主键候选和包含依赖，再利用LLM进行语义裁决；同时利用数据库查询历史动态优化连接推断。

Result: 在TPC-DS、TPC-H、BIRD-Dev及生产工作负载上的实验表明，该方法在结构良好的模式上达到78%–100%的高精度，同时揭示了在非规范化数据中连接发现的固有挑战。

Conclusion: 结合统计与LLM的方法能有效平衡语义理解与数据驱动推理，在保证可扩展性的同时显著提升连接推断的准确性和鲁棒性。

Abstract: Context graphs are essential for modern AI applications including question answering, pattern discovery, and data analysis. Building accurate context graphs from structured databases requires inferring join relationships between entities. Invalid joins introduce ambiguity and duplicate records, compromising graph quality. We present a scalable join inference approach combining statistical pruning with Large Language Model (LLM) reasoning. Unlike purely statistics-based methods, our hybrid approach mimics human semantic understanding while mitigating LLM hallucination through data-driven inference. We first identify primary key candidates and use LLMs for adjudication, then detect inclusion dependencies with the same two-stage process. This statistics-LLM combination scales to large schemas while maintaining accuracy and minimizing false positives. We further leverage the database query history to refine the join inferences over time as the query workloads evolve. Our evaluation on TPC-DS, TPC-H, BIRD-Dev, and production workloads demonstrates that the approach achieves high precision (78-100%) on well-structured schemas, while highlighting the inherent difficulty of join discovery in poorly normalized settings.

An RDB2RDF view can be materialized to improve query performance and data availability. This article proposes a formal framework for constructing the materialized data graph for an RDB2RDF view and for incrementally maintaining the view's data graph. The article also presents an architecture and algorithms for implementing the proposed framework.

### [6] [SpotIt+: Verification-based Text-to-SQL Evaluation with Database Constraints](https://arxiv.org/abs/2603.04334)
*Rocky Klopfenstein,Yang He,Andrew Tremante,Yuepeng Wang,Nina Narodytska,Haoze Wu*

Main category: cs.DB

TL;DR: SpotIt+ is an open-source tool that evaluates Text-to-SQL systems by finding database instances that reveal semantic differences between generated and ground-truth SQL queries, using a novel constraint-mining pipeline to ensure realistic counterexamples.


<details>
  <summary>Details</summary>
Motivation: Standard test-based evaluation of Text-to-SQL systems often fails to detect semantically incorrect queries that coincidentally produce correct results on given test databases. To address this, the authors aim to develop a more robust evaluation method based on bounded equivalence verification that finds meaningful discrepancies.

Method: SpotIt+ actively searches for differentiating database instances between a generated SQL query and its ground truth. It employs a constraint-mining pipeline that combines rule-based specification mining over example databases with LLM-based validation to ensure the generated counterexamples are realistic and practically relevant.

Result: Experiments on the BIRD dataset demonstrate that SpotIt+ with mined constraints produces more realistic differentiating databases while efficiently uncovering many discrepancies missed by standard evaluation methods.

Conclusion: SpotIt+ improves Text-to-SQL evaluation by enabling bounded equivalence verification with practical relevance, offering a more reliable alternative to conventional test-based approaches.

Abstract: We present SpotIt+, an open-source tool for evaluating Text-to-SQL systems via bounded equivalence verification. Given a generated SQL query and the ground truth, SpotIt+ actively searches for database instances that differentiate the two queries. To ensure that the generated counterexamples reflect practically relevant discrepancies, we introduce a constraint-mining pipeline that combines rule-based specification mining over example databases with LLM-based validation. Experimental results on the BIRD dataset show that the mined constraints enable SpotIt+ to generate more realistic differentiating databases, while preserving its ability to efficiently uncover numerous discrepancies between generated and gold SQL queries that are missed by standard test-based evaluation.

</details>
